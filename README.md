# NOA — Nail Atelier · אתר דמו למניקוריסטית

אתר דמו מלא (עברית / RTL) לסטודיו ציפורניים, שנבנה כדי להדגים לבעלות עסק
איך אתר מייצר פניות: גלריית עבודות מסוננת, מחירון שקוף, שאלון התאמה, וקביעת תור אינטראקטיבית.

**Stack:** HTML + CSS + Vanilla JS (ES Modules). בלי build, בלי framework, בלי dependencies.
פותחים קובץ אחד — האתר עובד.

---

## הרצה מקומית

מכיוון שהקוד משתמש ב-ES Modules, צריך שרת סטטי (לא לפתוח `index.html` ישירות מהדיסק):

```bash
python3 -m http.server 8080
# ואז: http://localhost:8080
```

או כל שרת סטטי אחר (`npx serve`, Live Server ב-VS Code וכו').

## פריסה (Deploy)

האתר סטטי לחלוטין — אפשר להעלות את התיקייה כמו שהיא ל-Netlify / Vercel / Cloudflare Pages /
GitHub Pages / כל אחסון רגיל. אין שלב build.

## מה מחליפים כשעוברים ללקוחה אמיתית

הכול מרוכז ב-**`assets/js/data.js`** (חוץ מטקסטים ארוכים שיושבים ישירות ב-`index.html`).

### 1. פרטי העסק
`STUDIO` בראש `data.js` — שם, טלפון (כולל `phoneIntl` לוואטסאפ), כתובת, אינסטגרם,
שעות פעילות, דירוג. הפרטים האלה מתפזרים אוטומטית לכל האתר: כפתורי וואטסאפ, פוטר, אזור צור קשר.

### 2. תמונות העבודות
1. שמים את הצילומים ב-`assets/img/works/`.
2. מעדכנים ב-`WORKS` את שדה ה-`img` (או פשוט שומרים בשמות `w01.jpg`, `w02.jpg`... ומשנים את
   הסיומת בשורת ה-`.map()` בסוף המערך).
3. שדות `alt` נוצרים אוטומטית מהכותרת והמאפיינים — טוב ל-SEO ולנגישות.

**מומלץ:** יחס תמונה 3:4 (לדוגמה 900×1200), עד ~200KB, פורמט WebP.

לכל עבודה יש:

| שדה | תפקיד |
|---|---|
| `tags` | הפילטרים בגלריה (`french`, `chrome`, `art`, `color`, `short`, `long`, `build`, `minimal`) |
| `vibe` | מנוע ההתאמה של "מצאי את הסט שלך" |
| `shape` / `length` | מוצגים במודאל ומשמשים בהתאמה |
| `service` | הטיפול שייבחר אוטומטית כשלוחצים "אני רוצה כזה" |

### 3. שירותים ומחירים
`SERVICES` — שם, שם אנגלי, תיאור, מחיר, משך, ו-`popular: true` לתג "הכי מבוקש".
המחירים מופיעים גם בכרטיסים, גם בקביעת התור וגם ב-structured data ב-`index.html` (לעדכן שם גם).

### 4. שאלות נפוצות, ביקורות, אזור אמון
`FAQ`, `REVIEWS`, `VALUES`, `STATS` — מערכים פשוטים.
בעדכון FAQ כדאי לעדכן גם את ה-`FAQPage` JSON-LD ב-`index.html`.

### 5. טקסטים ארוכים
פסקאות ה-About, כותרות הסקשנים והכתובת באזור צור קשר נמצאות ישירות ב-`index.html`
(כדי שיהיו ב-HTML עבור SEO).

### 6. אינסטגרם
`FEED` — כרגע מציג תמונות מקומיות עם קישור לפרופיל. אפשר להחליף לווידג'ט אמיתי
בלי לגעת בשאר האתר.

## מה עובד באמת (Frontend Demo)

- **גלריה מסוננת** — 9 פילטרים, טעינה מדורגת, מודאל עם ניווט בין עבודות (כולל מקשי חצים).
- **"אני רוצה כזה"** — מצרף את העיצוב שנבחר לתהליך קביעת התור, בוחר אוטומטית את הטיפול
  המתאים, ומציג thumbnail של העבודה בתוך ההזמנה ובסיכום.
- **"מצאי את הסט שלך"** — שאלון 3 שאלות עם מנוע ניקוד אמיתי (וייב ×3, אורך ×2, צורה ×2)
  שמחזיר 3 עבודות מתאימות מהגלריה.
- **קביעת תור** — 5 שלבים, תאריכים אמיתיים (שבת סגור, שישי קצר), תפוסה דמו יציבה,
  ולידציה לשם וטלפון, סיכום, ואישור. בסיום נוצר טקסט וואטסאפ מוכן עם כל פרטי התור.
- **FAQ** — accordion נגיש (`aria-expanded`).
- **מובייל** — Sticky bar עם WhatsApp / קביעת תור, תפריט מגירה, כל האינטראקציות ביד אחת.

### מה לא קיים (ובכוונה)
אין Backend. התור לא נשמר בשום מקום ואין סליקה. באתר חי מתחברים כאן ליומן
(Google Calendar / מערכת תורים) ולהודעות אוטומטיות.

## SEO

- HTML סמנטי, היררכיית כותרות תקינה (h1 יחיד, h2 לכל סקשן).
- `title`, `meta description`, Open Graph, canonical.
- Structured data: `BeautySalon` (כולל שעות, דירוג, קטלוג שירותים) + `FAQPage`.
- `alt` לכל תמונה, `lang="he"` ו-`dir="rtl"`.
- `robots.txt` ו-`sitemap.xml` בשורש.

**לפני העלייה לאוויר:** להחליף את `https://example.co.il/` ב-`index.html`, `robots.txt`
ו-`sitemap.xml` בדומיין האמיתי.

**הרחבה עתידית:** המבנה מאפשר להוסיף עמודי נחיתה לשירותים וחיפושים מקומיים
(למשל `/lak-gel-tel-aviv`) שיטענו את אותו `data.js` ויציגו את העבודות הרלוונטיות בלבד.

## ביצועים

- אפס dependencies, אפס בקשות לצד שלישי (הגופנים מקומיים).
- `loading="lazy"` + `width`/`height` לכל תמונה מתחת לקיפול (בלי CLS).
- אנימציות על `transform`/`opacity` בלבד, עם `IntersectionObserver`.
- כיבוד `prefers-reduced-motion`.

## תמונות ה-Placeholder

`tools/generate-placeholders.mjs` מייצר את כל התמונות כ-SVG (~10KB כל אחת).
זה נועד **רק לשלב הדמו** — כשמגיעים צילומים אמיתיים אפשר למחוק את הסקריפט ואת התיקייה.

```bash
node tools/generate-placeholders.mjs
```
